FAQ

1. How do I connect the DPF Load Monitor?

The DPF Load Monitor connects to the vehicle via the OBD2 port.

2. Do I need to unplug the DPF Load Monitor every time I turn off the engine?

No, the DPF Load Monitor does not need to be unplugged after turning off the vehicle. The device enters sleep mode automatically.

3. How do I mount the device?

Installation is done using double-sided tape (included with the device). You can attach the device to the vehicle's dashboard using either the bottom or the back surface of the unit.

5. Can I insert or remove the microSD card while the device is running?

Yes, you can insert and remove the microSD card while the device is running. You do not need to disconnect it from power.

6. Why doesn't the device remember the set time after disconnecting?

The device does not have a built-in battery to maintain the clock, so it loses the set time when disconnected from power. After reconnecting, you must set the time manually.
